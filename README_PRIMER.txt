CASA MESTRES · APP CONSOLIDADA

OBJECTIU
Una sola app local amb l’estructura acordada:
- Configuració: empresa, logotip, GPS, cartes, menús i pressupostos.
- Magatzem: proveïdors, productes i OCR directe.
- Cuina: bases de cuina i fitxes de plats amb escandall incorporat.
- Control de Qualitat: Control Normatiu complet.
- RRHH: empleats, horaris i registre GPS de fitxatges.

FORA DEL SISTEMA
- Tasques
- Notes de veu
- Mise en place
- Compres automàtiques
- Comptabilitat d’albarans
- Mòdul separat d’escandalls

COM OBRIR
1. Descomprimeix la carpeta.
2. Fes doble clic a INICIAR_CASA_MESTRES.bat.
3. S’obrirà http://127.0.0.1:3210

REQUISIT
Node.js instal·lat al PC. No necessita npm install ni Internet.

DADES I SEGURETAT
- Totes les dades són a data.json.
- Abans de cada guardat es crea una còpia automàtica a backups.
- El menú Còpies de seguretat descarrega/restaura tot el conjunt, inclòs Control Normatiu.
- data.original.json conserva l’estat inicial d’aquesta entrega.

IMPORTANT
No cal GitHub, Render ni PWA per provar-la. Primer s’audita localment tot el conjunt.
